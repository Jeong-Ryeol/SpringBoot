# UMC 8th - Spring Boot Study

UMC (University MakeUs Challenge) 8기 Spring Boot 스터디 워크북 및 미션 저장소입니다.

## 주차별 학습 내용

| 주차 | 주제 | 내용 |
|------|------|------|
| 0주차 | Java 기초 | Java 기본 개념 학습 |
| 1주차 | ERD 설계 | 데이터베이스 ERD 설계, 정규화, 연관관계 |
| 2주차 | 실전 SQL | JOIN, SubQuery, 페이징 기법, 쿼리 작성 |
| 3주차 | SQL 심화 | SQL 실습 및 미션 |
| 4주차 | Spring Boot 코어 | Spring Boot 핵심 개념 (IoC, DI, AOP 등) |
| 5주차 | JPA 기초 | JPA 기초 및 프로젝트 구조 설계 |
| 6주차 | JPA 활용 | JPA 활용 및 실습 |
| 7주차 | API 설계 | API 응답 통일, 에러 핸들러, 시니어 미션 |
| 8주차 | API & Swagger | API 개발, Swagger 문서화, 커스텀 어노테이션 |
| 9주차 | 프로젝트 실습 | 실전 프로젝트 적용 |
| 10주차 | 인증/인가 | 로그인 및 회원가입 구현 |

## 기술 스택

- **Language**: Java 17
- **Framework**: Spring Boot 3.x
- **ORM**: Spring Data JPA
- **Database**: MySQL
- **Docs**: Swagger

## 브랜치 구조

- `main` - 기본 브랜치
- `정렬/정원렬` - 개인 워크북 및 미션 제출 브랜치
